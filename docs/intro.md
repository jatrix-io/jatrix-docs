# Welcome to Jatrix

**Jatrix** is a SaaS Governance Engine designed to centralize identity, multi-tenancy, authorization, and product-level control for B2B software platforms.

## Contents

- **[API Reference](./api)** — Complete REST API v1 documentation

## What is Jatrix

Jatrix acts as the control layer for SaaS ecosystems. It provides:

- Global identity management
- Tenant isolation
- Authorization with product-scoped roles and permissions
- Entitlement control
- Structured audit trail
